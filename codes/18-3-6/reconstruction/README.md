# CodeA: a verified pure binary [[18,3,6]] stabilizer

Brandon Li, with help from Claude. This package specifies one construction and provides complete, reproducible checks.

## Quick verification

Use Python 3.10 or later, without optimization flags. No third-party packages are needed.

    python3 verify_standalone.py

The verifier is self-contained, including all 15 generator rows. It checks binary rank 15, pairwise symplectic commutation, constructs a fresh rank 21 normalizer basis, enumerates all 32,768 stabilizer words and 2,097,152 normalizer words, computes the complete weight distributions, verifies all 19 quaternary MacWilliams coefficients, and checks an explicit weight-six logical operator. Expected output is `STANDALONE_RESULT.json`.

To check the local gluing tables and reconstruct precisely the same rows:

    python3 construction/reconstruct_from_gluing.py

This independently recomputes every local coset minimum and checks all 1,023 nonzero quotient inequalities before reconstructing the 15 rows.

## Conventions and generators

A decimal row encodes `x | (z << 18)`. Bit i of x and bit i of z refer to site i, for zero-based sites 0 through 17. The local pairs 00, 10, 01, 11 mean I,X,Z,Y respectively. In `GENERATORS_PAULI.txt`, site 0 is the leftmost character and site 17 the rightmost. The independent summary labels the same positions qubits 1 through 18.

`RAW15.rows` begins with `18 15`, then one unsigned decimal generator per line. `RAW21_NORMALIZER.rows` similarly begins with `18 21`. `GENERATORS_PAULI.txt` contains the 15 explicit Pauli strings.

Each row means the corresponding Hermitian tensor product of I,X,Y,Z, chosen with +1 eigenvalue. Binary rows alone omit phases. The 15 independent commuting Hermitian generators define an 8-dimensional joint eigenspace: independence excludes any nonempty product proportional to identity, so the 15 constraints reduce dimension from 2^18 to 2^(18-15)=8. Other consistent generator-sign choices do not affect the distance calculation.

## What is proved

- Stabilizer binary rank:15.
- Normalizer binary rank:21.
- Encoded qubits:18−15=3.
- Minimum nonzero stabilizer weight:6.
- Minimum nonzero normalizer weight:6.
- Minimum weight in normalizer minus stabilizer:6.

The exhaustive absence of normalizer words of weights 1 through 5 proves distance at least 6. The explicit operator 34359939617 has weight 6, commutes with every generator, and is outside the stabilizer, proving distance exactly 6. Its Pauli string is in `LOGICAL_WITNESS.json`. The minimum stabilizer weight also equals 6, so the construction is pure.

There are 588 normalizer words of weight 6: 4 stabilizers and 584 nontrivial logical operators. Stabilizer counts include A6=4, A7=0, A8=130 and A9=480. The exact full distributions at every weight 0 through 18 are in `ENUMERATORS.csv`, `STANDALONE_RESULT.json` and `PRODUCER_PHYSICAL_VERIFICATION.json`.

A separate check enumerated all 2,353,347 physical Pauli errors of weights 1 through 5 and found no zero syndrome. Its source and output are in `independent_checks/check_errors.cpp` and `check_errors.log`. To repeat it with GCC:

    g++ -O3 -std=c++17 independent_checks/check_errors.cpp -o check_errors
    ./check_errors

The primary Python verifier does not require a compiler.

## Construction and provenance

The construction glues an 8-site isotropic rank-four code with a marked rank-two shortening to a 10-site rank-seven, Gram-rank-two code with a marked rank-three radical subspace. The local quotient spaces have binary dimension 10 and Poisson rank 8. The explicit linear quotient map and physical bases are provided in `construction/HIT.json` and `construction/PHYSICAL_HIT_CONTEXT.json`.

The global normalizer is generated by the two local codes and 10 paired quotient lifts. Its symplectic orthogonal complement yields the 15 stabilizer rows. The resulting physical code is verified independently of this search description by the primary verifier.

`PROVENANCE.json` records the actual local generators and coordinate placement. Numeric record IDs are search labels.

## Optional deterministic search replay

A one-ingredient replay is included. It requires GCC-compatible C++17 and an AVX2-capable CPU. This replay is optional; verification above is portable and sufficient.

    g++ -O3 -mavx2 -std=c++17 search_source/search.cpp -o search
    ./search search_input 0 1 32 100000 0 search_input/TARGET.tsv

The input retains the original left-table indexing and physical right ingredient, so the random seed and search order are reproducible. A successful replay writes its map and physical context into `search_input/`. These do not replace the authoritative construction files.
