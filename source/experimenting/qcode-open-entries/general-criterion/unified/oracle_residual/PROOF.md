# Disjoint Oracle producer

The frozen residual theorem, physical symmetry, Z enumeration and Y solver are
unchanged. The Oracle producer compiles the exact frozen C source using GCC on
Linux in this new namespace. The original Mac binaries are retained as reference
bytes; their hashes in the base manifest do not claim that Linux executes them.
The additional linux_compact/linux_joint hashes identify the actual executables.
All production records carry this separate producer manifest and admission hash.

Admission requires eight COMPLETE native stream hashes and all non-time counters
to equal exact Mac reference runs, byte-identical reconstructed native inputs,
and twelve genuine [[17,3,3]] controls spanning every residual H class. Controls
exercise both Linux backends and independent full physical dual-word checks.
These are compiler/platform controls, not proofs of compiler correctness or new
distance-six exclusions. The trusted native implementation remains the same.

The immutable assignment partitions all suffix classes into disjoint Mac and
Oracle sets. Oracle uses no stream reuse: it enumerates every assigned chunk and
solves every returned Y leaf itself. Limits, process errors, missing records and
positive candidates never exclude. Raw candidates are persisted before physical
verification, as in the frozen runner. A bounded free-space guard stops dispatch
without overwriting checkpoint evidence.

The new union aggregator reconstructs all expected tasks using the frozen
coverage code, applies its strict verifier to each remote record with the new
known producer manifest, and retains the frozen verifier for all original Mac
records including exact-input reuse. Misassigned classes, foreign manifests,
unfinished work and orphan records prevent closure. The bridge copies atomic
checkpoints without deleting remote evidence. Final classification and whole
theorem review remain separate obligations. No model API or Claude callback is
used by these processes.
